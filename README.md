## 1. Product Overview

**InkFlow Studio** is a native Android application designed from the ground up for tablets, foldables, and stylus-equipped devices (Samsung S-Pen, Lenovo Precision Pen, Xiaomi Smart Pen, and standard capacitive styluses).

It delivers a focused, distraction-free environment where students, researchers, teachers, and professionals can handwrite, sketch, annotate PDFs, record audio notes with synchronized stroke replay, organize thoughts on an infinite whiteboard, and practice with spaced repetition.

### Non-Negotiable Principles
- **Ink First:** Every stroke is stored and rendered as an uncompressed vector path with pressure and temporal metadata—never a flattened screenshot.
- **Offline by Default:** All note creation, editing, PDF viewing, audio recording, and AI study workflows function 100% offline without requiring account sign-in or cloud connections.
- **User Owns the Data:** Local SQLite Room database and transparent JSON stroke files in sandboxed app storage. Instant export to PDF, PNG, and `.inkflow` interchange archives.
- **Privacy Transparent:** Zero third-party ad/analytics trackers. The built-in "Ask InkFlow" assistant runs completely on-device.

## 2. Core Workspaces

### 1. Notebook Workspace
- Multi-page notebooks with seamless page addition, reordering, and deletion.
- **Paper Templates:** Blank, Ruled, College Ruled, Dotted, Grid, Cornell Notes, and Checklist.
- **Tool System:** Fountain Pen (pressure-sensitive), Ballpoint, Pencil (graphite grain), Highlighter (high-fidelity alpha blending), Stroke/Pixel Eraser, and Pan/Zoom.
- **Color Palette:** Presets plus custom HEX/RGB swatches.
- **Undo / Redo:** Robust command-based undo/redo stacks per page.

### 2. PDF Markup Workspace
- Import any PDF document via Android's Storage Access Framework (`ACTION_OPEN_DOCUMENT`).
- Hardware-accelerated multi-page rendering using native `android.graphics.pdf.PdfRenderer` with memory-bounded LRU caching.
- Vector ink annotation overlay anchored to PDF coordinates.
- Export annotated PDFs using `android.graphics.pdf.PdfDocument` compositing original pages with user vector ink.

### 3. Infinite Whiteboard Workspace
- Non-paginated 2D spatial canvas with pinch zoom and pan navigation.
- Mixed-content canvas objects: color-coded sticky notes, geometric shapes (rectangles, circles), text cards, and freehand ink.
- One-tap "Center on Content" viewport reset.

### 4. Audio Notes & Synchronized Replay
- High-fidelity AAC/M4A audio recording powered by Android's `MediaRecorder`.
- Strokes drawn while recording record millisecond timestamps.
- During playback, active strokes highlight dynamically in synchronization with audio playback.

### 5. Study Workspace (Spaced Repetition)
- Flashcards created manually or auto-generated by the AI assistant.
- SuperMemo SM-2 algorithm: reviews scheduled with ratings (`Again`, `Hard`, `Good`, `Easy`), dynamic interval calculations, and ease factors.

### 6. "Ask InkFlow" On-Device AI Assistant
- Extractive summarizer, concept extractor, and flashcard synthesizer running 100% on-device with zero network latency or external dependencies.

## 3. Prerequisites & Environment

- **Operating System:** macOS, Linux, or Windows (tested on macOS Darwin aarch64)
- **JDK:** OpenJDK 21 (Temurin JDK 21 recommended)
- **Android SDK:** Platforms `android-35` or `android-36`, Build-Tools `35.0.0` or `36.1.0`
- **Gradle:** 8.14.3 (included via `./gradlew`)

## 4. Build & Installation

### Environment Configuration
```bash
export JAVA_HOME="/Library/Java/JavaVirtualMachines/temurin-21.jdk/Contents/Home"
export ANDROID_HOME="$HOME/Library/Android/sdk"
```

### Compile Debug APK
```bash
./gradlew assembleDebug
```
The installable APK will be generated at:
```
app/build/outputs/apk/debug/app-debug.apk
```

### Run Unit Tests
```bash
./gradlew test
```

### Install onto Device / Emulator
```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

---

## 5. Permission Model
- `android.permission.RECORD_AUDIO`: Requested strictly when activating audio recording within a note.
- `android.permission.INTERNET`: Used only if optional external AI APIs are explicitly configured with user consent.
- Storage uses the modern Android Storage Access Framework (SAF), requiring no broad external storage permissions.
